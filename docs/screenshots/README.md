## How to capture

1. Run the web app locally or use the deployed Azure URL.
2. Use a 390×844 viewport (iPhone 14) for mobile-style crops.
3. Blur or use stock photos — do not include real user PII in public screenshots.

Reference these paths from [README.md](../../README.md) once files are added.
